# 직업 및 스킬 트리

Rovenfall의 직업 트리는 서버가 검증하는 데이터 기반 방향성 비순환 그래프다. Path of Exile의
패시브 트리에서 참고한 핵심은 **작은 노드 투자 → 서로 다른 전문 경로 → 두 경로가 다시 만나는
키스톤** 구조이며, 특정 게임의 능력이나 수치를 그대로 복제하지 않는다. 플레이어는 어느 경로를
먼저 올릴지 선택하지만, 최종 키스톤은 두 갈래를 모두 익혀야 열린다.

## 직업 계보

- 1티어: 모험가
- 2티어: 전사, 장인, 정찰자
- 3티어: 선봉대·처단자, 건축가·경작가, 선구자·레인저
- 4티어 전투: 철벽 수호자·전쟁 지휘관, 사신·야수 조련사
- 4티어 제작: 룬 대장장이·공학자, 연금술사·영지 관리인
- 4티어 탐사: 길잡이·심층 탐사자, 매사냥꾼·그림자 사냥꾼

4티어 직업은 주 활동 레벨 8과 보조 활동 레벨 5~7을 요구한다. 승급 시 스킬 포인트 4점을
받으며, 같은 3티어 아래의 다른 전문화로 전환하면 기존 형제 전문화와 그 하위 진행도만 명시적
확인 후 초기화된다. 조상 직업의 진행도는 유지된다.

## 4티어 스킬 트리 규칙

각 전문화는 네 종류의 노드로 구성된다.

1. **기반 노드**: 주 활동 경험치 보너스, 최대 3랭크.
2. **전문 경로 A**: 기반 노드가 필요하며 보조 활동을 강화, 최대 2랭크.
3. **전문 경로 B**: 기반 노드가 필요하며 주 활동을 더 강화, 최대 2랭크.
4. **키스톤**: 두 전문 경로가 모두 필요하고 2포인트를 소비한다. 모든 활동에 작은 보너스를
   더하고 직업 정체성에 맞는 액티브 효과를 해금한다.

모든 해금, 초기화, 액티브 슬롯 및 재사용 대기시간은 기존 서버 권한 서비스가 검증한다. 데이터
팩은 그래프와 밸런스를 정의할 뿐 클라이언트가 랭크나 효과를 직접 변경할 수 없다.

## 기존 직업 보강

1~3티어의 기존 10개 직업에도 각각 패시브 노드와 합류형 액티브 노드를 하나씩 추가한다.
전사·처단자·레인저는 서버가 계산하는 공격 피해 증가, 모험가·정찰자·선봉대·선구자는 받는
피해 감소를 제공한다. 장인·건축가·경작가는 기존 provenance와 anti-farming 판정을 통과한
생활 활동 경험치만 강화한다. 공격 증가와 피해 감소는 각각 50%에서 상한을 적용하며, 발사체는
서버가 확인한 실제 소유자를 기준으로 계산한다.

새 액티브 노드는 기존 주 경로와 새 패시브 경로를 모두 요구한다. 따라서 기존 직업도 한 줄짜리
진행이 아니라 두 갈래를 투자한 뒤 전장의 함성, 그림자 걸음, 전선 사수, 위대한 설계 같은
역할별 액티브에 도달한다.

## 보스 전투 적용 원칙

황야 경기장 수호자는 MMORPG 레이드에서 널리 쓰이는 **명확한 예고 후 회피** 원칙을 따른다.
2단계부터 가장 먼 플레이어의 현재 바닥을 표시한 뒤 1.5초 후 폭발시키며, 3단계에서는 경기장
외곽을 예고한 뒤 피해 구역으로 만들어 중앙 집결을 요구한다. 기존 근접 휩쓸기, 충격파, 하수인
소환과 겹치므로 공격만 반복하는 대신 위치 선정과 팀 이동이 필요하다. 표적 위치와 남은 예고
시간은 엔티티 저장 데이터에 보존되어 서버 재시작으로 예고를 무효화할 수 없다.
