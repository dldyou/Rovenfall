# 룬 파수꾼

야생 동굴에서 만나는 일반 정예 몹입니다. 기본 좀비 모델을 사용하며, 햇빛에 타거나 물속에서 다른 몹으로 변하지 않습니다.

## 전투와 회피

- 체력 40, 기본 근접 공격력 5입니다. 실제 피해는 난이도·방어구 등 기본 전투 규칙을 따릅니다.
- 8블록 안의 플레이어를 바라볼 수 있으면 **그 순간의 발밑 위치**에 룬 원을 표시합니다.
- 경고음과 원형 입자가 나타난 뒤 1.4초 후, 원래 위치에서 반경 1.75블록 안에 남은 대상에게 기본 피해 7을 한 번 줍니다. 다른 플레이어에게 전이되는 광역 공격은 아닙니다.
- 원 밖으로 이동하면 피할 수 있습니다. 점프만으로 피하기보다는 옆으로 이동하세요.
- 시전 후 1.2초 동안 이동·근접 공격을 쉬므로 이때 반격하세요. 다음 시전까지 추가로 5초가 필요합니다.
- 대상 사망·차원 이동·시야 상실·사거리 이탈·보호 구역 진입 시 시전을 취소합니다. 중단한 시전은 청크 재로딩 후 즉시 폭발하지 않고 새 경고부터 시작합니다.
- 룬 공격은 블록을 부수거나 불을 붙이지 않습니다. 보호 구역과 야생 작업 잠금은 타격 전에도 검사합니다.

## 출현과 보상

야생의 점적석·무성한·유황 동굴 및 깊은 어둠 생물 군계에서 Y -64~96에 단독 출현합니다. 생물 군계 스폰 가중치는 4이며, 기본 적대 몹 스폰 조건을 통과한 후보 중 10%가 허용됩니다. 따라서 전체 몹의 10%라는 뜻은 아닙니다. 허브·보호 구역에서는 명령어 소환도 거부됩니다.

플레이어 처치 시 룬결속 파편 1개와 기본 경험치 구슬 18을 지급합니다. 파편은 [원정 장비의 인챈트 책 제작](expedition-equipment.md)에 사용합니다. 별도의 마지막 타격 화폐 보상은 없습니다.

여정 메뉴 → 일일 과제의 **룬 파수꾼 진압**은 해당 몹의 사냥 기여 경험치 210을 모아 화폐 240을 받는 과제입니다. 완료한 뒤 직접 수령하며 기존 UTC 일일 초기화·중복 수령 방지 규칙을 따릅니다. 사냥 기여 경험치는 단순 처치 횟수가 아닙니다.

## 운영자와 개발자

밸런스는 `data/rovenfall/rovenfall/mob_content/rune_sentinel.json`의 `rune_strike`로 설정합니다. 예고·회복·쿨다운, 거리·반경·피해는 범위와 유한수 검증을 거치며 잘못된 후보는 이전 정의를 교체하지 않습니다. 전리품·활동 보상·일일 과제는 각각의 기존 데이터 경로에서 설정합니다.

`runWildernessGameTestServer`는 `src/gametest/datapack`의 테스트 전용 평지 프리셋으로 실제 `rovenfall:wilderness` 차원을 생성합니다. 기본 GameTest 서버는 일반 차원 JSON을 무시하므로 Minecraft의 `--packs` 옵션을 사용합니다. 야생 차원 부재를 검증하는 기존 초기화 테스트와 섞이지 않도록 별도 작업 디렉터리와 테스트 선택자를 사용합니다. 이 데이터 팩은 운영 JAR에 포함하지 않습니다.

`releaseCheck`는 기존 서버 테스트와 이 야생 전용 테스트를 모두 실행합니다. 야생 전용 테스트는 예고 시간·회피·단발 피해·회복·쿨다운·대상 상실·차원 이탈·허브 소환 거부·저장/복원 시 새 예고·공격자와 다른 청크에 있는 대상의 보호 구역을 검증합니다. 결과는 `build/gametest-results.xml`과 `build/wilderness-gametest-results.xml`에 기록합니다.

클라이언트에서 경고 원의 가독성, 작은 GUI 배율, 다른 HUD와의 조화는 별도의 실제 플레이 확인이 필요합니다.
