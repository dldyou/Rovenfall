# 기본 밸런스 기준표

이 문서는 현재 배포 데이터의 기준값과 조정 위치를 빠르게 찾기 위한 운영 색인이다. 숫자의 단일 진실 원천은 코드 상수 또는 아래 JSON 파일이며, 이 문서를 먼저 수정해서는 안 된다.

## 경제와 토지

| 항목 | 기본값 | 조정 위치 |
| --- | ---: | --- |
| 신규 잔액 | 0 | `economy.initial_balance` |
| 최대 잔액 | `Long.MAX_VALUE` | `economy.maximum_balance` |
| 고액 거래 경고 | 100,000 | `economy.alert_amount` |
| 거래 빈도 경고 | 60초 내 20건 | `economy.alert_rate`, `economy.alert_window_seconds` |
| 첫 토지 가격 | 1,000 | `claims.base_price` |
| 추가 토지당 인상 | 250 | `claims.price_increase` |
| 토지 소유 한도 | 64 | `claims.ownership_cap` |
| 판매 환급률 | 50% | `claims.sale_refund_percent` |
| Hub 스폰 보호 반경 | 2청크 | `claims.protected_spawn_radius_chunks` |

## 활동과 직업

활동 레벨 곡선은 `activity_levels/*.json`, 보상과 60초 anti-farming 한도는 `activity_rewards/*.json`에 있다. 기본 팩은 7개 트랙에 총 80개 보상 정의를 제공한다.

| 트랙 | 기본 대상과 단위 XP |
| --- | --- |
| 건축 | 조약돌·참나무 판자 1, 석재 벽돌·벽돌·유리 2 |
| 요리 | 구운 감자 1, 익힌 소고기·닭고기·돼지고기·대구·연어 2, 고원 치즈 제작 4, 개척자 스튜 제작 5 |
| 채광 | 일반/심층암 광석 1~10, 네더 석영 2, 네더 금 3, 고대 잔해 15 |
| 탐험 | 주요 지상 생물군계와 점적석·무성한·유황 동굴·깊은 어둠 최초 발견 30 |
| 농사 | 성숙한 밀·당근·감자·비트 4, 소·돼지·양·닭 번식 10, 염소 번식 12 |
| 전투 | 일반 적 피해 기여 1, Rovenfall 일반 몹 2~3, 경기장 수호자 4 |
| 사냥 | 일반 적 처치 기여 1, Rovenfall 일반 몹 2~3, 경기장 수호자 4 |

신규 성장 트랙 정의는 `professions/*.json`에 있다. 기존 RPG 직업 정의는 `careers/*.json`을 유지한다.

- 모험가: 무료, 모든 활동 트랙, 스킬 초기화 100
- 전사: 전투 2·사냥 1 요구, 승급 100, 승급 스킬 포인트 1
- 장인: 요리 1·건축 2·농사 1 요구, 승급 100, 승급 스킬 포인트 1
- 정찰자: 탐험 2·사냥 2 요구, 승급 100, 승급 스킬 포인트 1. `길잡이`는 탐험 XP와 신속 액티브, `예리한 감각`은 사냥 XP와 야간 투시 액티브를 제공한다.
- 전사·장인·정찰자는 같은 2티어 분기이므로 전환 시 기존 형제 분기와 그 하위 진행도가 명시적 확인 후 초기화된다.

각 2티어 직업은 활동 레벨 4~5에서 두 개의 3티어 전문화로 갈라진다. 승급 비용은 300, 승급 스킬 포인트는 2, 스킬 초기화 비용은 150이다.

| 선행 직업 | 3티어 전문화 | 요구 조건 | 주력 활동 |
| --- | --- | --- | --- |
| 전사 | 선봉대 | 전투 5, 사냥 3 | 전투 방어·파티 돌파 |
| 전사 | 처단자 | 전투 4, 사냥 5 | 추격·마무리 공격 |
| 장인 | 건축가 | 건축 5, 채광 3 | 건축·채광 |
| 장인 | 경작가 | 요리 4, 농사 5 | 농사·요리 |
| 정찰자 | 선구자 | 채광 4, 탐험 5 | 탐험·지하 탐사 |
| 정찰자 | 레인저 | 탐험 4, 사냥 5 | 장거리 이동·사냥 |

같은 선행 직업 아래의 3티어 전문화를 바꾸면 기존 전문화 진행도만 초기화되고, 2티어 선행 직업과 공통 조상 진행도는 유지된다.

플레이어는 `/rovenfall career info`에서 전체 직업 ID와 티어를 보고, `/rovenfall career explain rovenfall:scout`에서 정찰자 승급 조건과 초기화 영향을 미리 확인할 수 있다.

## 황야 도전과제

`activity_challenges/*.json`에는 활동 레벨을 조건으로 하는 1회성 목표 10개가 있다. 완료 여부는 별도 저장 데이터를 만들지 않고 플레이어 UUID와 도전과제 ID로 결정되는 경제 영수증으로 보존된다.

| 도전과제 | 요구 조건 | 화폐 보상 |
| --- | --- | ---: |
| 황야의 첫걸음 | 탐험 1, 사냥 1 | 100 |
| 심층 탐사자 | 채광 2, 탐험 1 | 150 |
| 자급자족 거점 | 요리 1, 건축 2, 농사 2 | 200 |
| 괴물 사냥꾼 | 전투 3, 사냥 3 | 250 |
| 황야의 베테랑 | 전투·채광·탐험·사냥 5 | 500 |
| 만능 개척자 | 활동 7종 모두 3 | 750 |
| 심층의 전설 | 채광 8, 탐험 6 | 700 |
| 거장의 손길 | 요리·건축·농사 7 | 900 |
| 개척지의 파수꾼 | 전투·탐험·사냥 8 | 1,100 |
| 로벤폴의 전설 | 활동 7종 모두 10 | 2,500 |

플레이어는 인벤토리의 **Skills → Challenges**에서 진행 상황을 보고 지급 가능한 보상을 한 번에 받을 수 있다. `/rovenfall challenge list`, `/rovenfall challenge info <id>`, `/rovenfall challenge claim <id>`는 운영·진단용 대체 경로로 유지한다. 보상이나 조건 변경은 데이터 팩 재적용으로 반영되며, 이미 완료한 ID는 보상 액수가 바뀌어도 다시 지급되지 않는다.

## 주간 황야 원정

`weekly_expeditions/*.json`에는 같은 주에 수령한 일일 의뢰 완료 횟수를 묶는 주간 목표 5개가 있다. 별도 진행도 저장 없이 일일 의뢰의 결정적 경제 영수증을 집계하며, 매주 월요일 00:00 UTC에 새 기간이 시작된다.

| 원정 | 요구 조건 | 화폐 보상 |
| --- | --- | ---: |
| 보급선 유지 | 철맥 돌파·수확 보급·야영지 식량·개척자의 만찬·고원 목축·고원 보급식 각 2일 | 1,000 |
| 위협 억제 | 좀비 소탕·해골 순찰대 각 2일, 전용 일반 몹 의뢰 7종 각 1일 | 1,450 |
| 변경의 이변 | 생물군계 전용 몹 의뢰 5종 각 2일 | 1,450 |
| 수호자의 맹세 | 수호자의 시험 3일 | 1,000 |
| 황야 원정 작전 | 일일 의뢰 16종 각 2일 | 3,900 |

플레이어 명령은 `/rovenfall expedition list`, `/rovenfall expedition info <id>`, `/rovenfall expedition claim <id>`다. 완료 및 보상 영수증은 30일간 보존되므로 현재 7일 주간 집계와 중복 지급 방지에 충분하며, 데이터 팩에서 존재하지 않는 일일 의뢰를 참조하면 전체 재적용이 실패한다.

## 황야 발전과제

Minecraft 기본 발전과제 화면에 황야 콘텐츠 동선을 제공한다. 별도 퀘스트 상태는 만들지 않으며 완료 상태와 화면 표시는 바닐라 플레이어 발전과제 데이터가 담당한다.

| 발전과제 | 완료 조건 |
| --- | --- |
| 황야의 부름 | 황야 차원 진입 |
| 황야 아래 | 점적석·무성한·유황 동굴과 깊은 어둠을 각각 발견 |
| 황야의 만찬 | 개척자 스튜 섭취 |
| 고원 목축가 | 새끼 염소 번식 |
| 고원 보급식 | 고원 치즈 섭취 |
| 황야의 사냥꾼 | 전용 일반 몹 7종을 각각 처치 |
| 개척 연금술사 | 사냥 영약 7종을 동시에 소지 |
| 봉인을 깨는 자 | 황야에서 수호자 도전 인장 사용에 성공 |
| 수호자의 몰락 | 경기장 수호자 기여도 기준을 충족하고 보상 획득 |
| 수호자 파쇄검 | 모든 황야 전리품과 수호자 핵으로 최종 사냥검 제작 |

`수호자의 몰락`은 마지막 타격 여부가 아니라 기존 보스 보상 판정을 따른다. 처치 직후 접속 중인 적격 기여자에게 지급하며, 보상이 오프라인에서 확정됐거나 발전과제·유물 보상이 뒤늦게 추가된 경우에는 다음 로그인 때 기존 보상 쿨다운 기록을 근거로 보완 지급한다.

## 제작 장비와 소모품

일곱 전용 재료는 기본 0~1개를 드롭하며 약탈 마법으로 추가 수량을 얻을 수 있다. 재료를 처음 획득하면 대응 제작법이 레시피 북에 해금된다.

| 결과물 | 모양 없는 조합 | 효과 | 최대 중첩 |
| --- | --- | --- | ---: |
| 개척자 스튜 | 구운 감자 + 익힌 소고기 + 그릇 + 당근 + 갈색 버섯 | 허기 10 회복, 재생 I 5초 | 16 |
| 개척자 사료 4 | 밀 + 당근 + 비트 + 밀 씨앗 | 소·돼지·양·닭·염소를 번식 준비 상태로 전환 | 64 |
| 고원 치즈 2 | 우유 양동이 + 밀 + 갈색 버섯 | 허기 6 회복, 점프 강화 I 45초 | 16 |
| 늪수호 영약 | 늪송곳니 독샘 + 꿀이 든 병 | 독 해제, 재생 I 10초 | 16 |
| 잿불수호 영약 | 잿불 핵 + 꿀이 든 병 | 화염 저항 I 3분 | 16 |
| 잿빛 장막 영약 | 잿빛 잔재 + 꿀이 든 병 | 신속 I 1분, 투명화 15초 | 16 |
| 룬수호 영약 | 룬결속 파편 + 꿀이 든 병 | 흡수 I 2분, 저항 I 30초 | 16 |
| 서리걸음 영약 | 서리결속 파편 + 꿀이 든 병 | 둔화 해제, 점프 강화 II 2분, 느린 낙하 30초 | 16 |
| 파도숨결 영약 | 파도결속 비늘 + 꿀이 든 병 | 채굴 피로 해제, 수중 호흡 I 3분, 돌고래의 우아함 45초 | 16 |
| 심층시야 영약 | 심층암 핵 + 꿀이 든 병 | 어둠 해제, 야간 투시 I 5분, 성급함 II 2분 | 16 |

영약은 서버에서 소비 효과를 적용하며 사용 후 유리병을 돌려준다. 별도 플레이어 상태나 장기 영속 데이터는 만들지 않는다.

| 무기 | 조합 | 기본 성격 | 적중 효과 |
| --- | --- | --- | --- |
| 늪송곳니 단검 | 늪송곳니 독샘 + 철 재료 + 막대기 | 철 등급, 빠른 공격 | 독 I 3초 |
| 잿불검 | 잿불 핵 + 철 재료 + 막대기 | 철 검 등급, 불에 타지 않음 | 4초간 점화 |
| 수호자 파쇄검 | 수호자 핵 + 잿불검 + 늪송곳니 단검 + 잿빛 잔재 + 룬결속 파편 + 서리결속 파편 + 파도결속 비늘 + 심층암 핵 + 네더라이트 주괴 | 네더라이트 검 등급, 에픽, 불에 타지 않음 | 약화 I 5초 |

무기 내구도와 수리는 각 바닐라 도구 등급 규칙을 따르고, 추가 적중 효과는 서버에서만 적용된다. 수호자 파쇄검은 모양 없는 조합이며 재료로 넣은 기존 두 무기의 내구도와 관계없이 완성품은 새 상태로 만들어진다.

## 플레이어 보스 도전

`수호자 도전 인장`은 늪송곳니 독샘 2개, 잿불 핵 2개, 다이아몬드 1개로 제작한다. 인장에 필요한 두 재료를 모두 획득하면 제작법이 해금되며, 황야에서 우클릭하면 사용 위치를 중심으로 반경 24블록의 경기장 수호자 전투가 시작된다.

전투 시작이 확정된 뒤에만 인장 1개가 소모된다. 황야 밖에서 사용하거나 다른 보스 전투가 진행 중이거나 소환이 실패하면 소모되지 않는다. 시작 행위는 플레이어 UUID와 함께 감사 로그에 남고, 기존 보스 규칙에 따라 최소 피해 20 및 전체 기여도 5%를 충족한 플레이어에게 250 화폐를 지급한다. 개인 보상 쿨다운은 6시간이다.

인장 사용 성공자는 `봉인을 깨는 자`, 적격 보상 수령자는 `수호자의 몰락` 발전과제를 각각 완료한다. 적격 보상을 처음 받은 플레이어에게는 `수호자 핵` 1개와 수호자 파쇄검 제작법도 개인 지급된다. 수호자 핵은 숨겨진 바닐라 발전과제 완료 상태로 중복 지급을 막으며, 이후 반복 처치 보상은 기존 250 화폐와 일일·주간 진행도만 제공한다.

## 변이 몹

`mob_mutations/*.json`에서 확률·속성·AI·통화 보상을 조정한다.

| 변이 | 생성 확률 | 체력 | 이동 속도 | 추가 특성 | 보상 |
| --- | ---: | ---: | ---: | --- | ---: |
| 잿불 | 4% | +35% | +12% | 집요한 추격 | 12 |
| 폭풍 | 3% | +25% | +18% | 도약 공격 | 16 |
| 철벽 | 2% | +75% | -10% | 밀치기 저항 +0.5, 집요한 추격 | 24 |
| 광란 | 2.5% | +20% | +30% | 공격력 +25%, 도약 공격 | 20 |

변이 확률은 해당 몹에게 적용 가능한 정의만 합산된다. 네 변이에 모두 해당하는 좀비의 총 변이 확률은 11.5%이며, 전체 카탈로그 확률 합계는 안전 상한 25% 아래로 검증된다.

밸런스 변경 후에는 데이터 코덱 테스트, 전체 단위 테스트, GameTest를 다시 실행하고 운영 검색의 `alerts` 범위에서 경제 경고가 과도하게 발생하지 않는지 확인한다.
