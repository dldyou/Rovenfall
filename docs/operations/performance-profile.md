# 20–50명 운영 상태 성능 프로파일

측정일: 2026-09-02
대상: Minecraft 26.2 / NeoForge 26.2.0.66 / Java 25
자동 회귀 테스트: `OperationsScaleTest`

## 시나리오

Minecraft 서버의 상태 변경은 메인 서버 스레드에서 직렬화되므로, 여기서 “50명 동시 접속”은 50명의 요청이 같은 운영 상태에 연속해서 도착하는 최악 쪽의 상태 계층 부하를 뜻한다. 테스트는 다음을 한 번에 수행한다.

- 플레이어 50명
- 플레이어당 경제 거래 20건, 총 1,000건
- 기본 rate 기준에 따른 플레이어별 경제 경고 1건, 총 50건
- 전체 `PlatformSavedData` 코덱 저장/재로드
- 플레이어·잔액·거래·경고 전체 검색
- 거래 필터 검색 25회
- 검색 결과 페이지 최대 50행 및 검색의 무변경성 검증

## 기준 측정

현재 호스트의 단독 테스트 실행 결과:

| 구간 | 측정값 |
| --- | ---: |
| 1,000건 쓰기 | 47 ms |
| 저장 후 재로드 | 89 ms |
| 전체/필터 검색 | 101 ms |
| 테스트 총계 | 310 ms |

이 값은 JUnit 프로세스가 준비된 상태의 단일 측정이며 하드웨어 간 절대 성능 보장은 아니다. 자동 회귀 한도는 환경 편차를 고려해 총 15초로 넉넉하게 두었다. 정확성 조건과 페이지 상한이 먼저이며, 한도 초과는 알고리즘 또는 코덱 회귀를 조사하라는 신호다.

## 재현

```powershell
.\gradlew.bat test --offline --tests org.dldyou.rovenfall.administration.OperationsScaleTest
```

측정 세부값은 `build/test-results/test/TEST-org.dldyou.rovenfall.administration.OperationsScaleTest.xml`의 표준 출력에 기록된다.

## 해석 범위

이 프로파일은 영속 상태, 거래 인덱스, 이상 징후 평가, 관리자 검색의 20–50명 목표를 검증한다. 네트워크 RTT, 청크 생성, 엔티티 AI, 렌더링, 실제 서버 틱 시간은 포함하지 않는다. 월드/몹 동작은 별도 GameTest로 검증하고, 실서버 릴리스 후보에서는 spark/JFR 같은 서버 프로파일러로 MSPT와 힙을 추가 관찰해야 한다.
