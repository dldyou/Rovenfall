# Rovenfall 로컬 운영 콘솔

Rovenfall 서버가 실행되면 관리 콘솔이 기본적으로 `http://127.0.0.1:8765/`에 열립니다. 콘솔의 정적 파일과 HTTP 브리지는 모드 JAR 안에 함께 들어가므로 별도 웹 서버나 데이터베이스가 필요하지 않습니다.

## 접속

1. Minecraft 서버를 시작합니다.
2. 서버의 `config/rovenfall-admin.token` 파일을 엽니다.
3. 브라우저에서 `http://127.0.0.1:8765/`에 접속한 뒤 토큰을 붙여넣습니다.

토큰은 브라우저 탭의 `sessionStorage`에만 보관되며 탭을 닫으면 사라집니다. 서버 로그에는 토큰 값이 출력되지 않습니다. 토큰 파일 대신 `ROVENFALL_ADMIN_TOKEN` 환경 변수에 32자 이상의 비밀값을 설정할 수도 있습니다.

브리지는 보안을 위해 항상 IPv4 루프백(`127.0.0.1`)에만 바인딩됩니다. 원격 서버를 관리하려면 로컬 PC에서 다음과 같이 SSH 터널을 연 뒤 동일한 로컬 주소로 접속합니다.

```bash
ssh -L 8765:127.0.0.1:8765 user@example-server
```

인터넷에 포트를 직접 공개하거나 토큰 파일을 공유 저장소에 올리지 마세요.

## 기능

- 서버 현황: 온라인/기록 사용자, 최근 24시간 거래와 거래량, 클레임, 상점, 경고 및 거부 건수
- 사용자: 닉네임 또는 UUID 검색, 잔액·역할·커리어·활동 경험치·소유 클레임 조회
- 감사 로그: 전체 텍스트, 사용자, 작업, 결과, 시간 범위 필터 및 페이지 조회
- 경제·클레임·상점: 거래 영수증, 되돌림 상태, 소유권, 위치, 오퍼 현황 검색
- 관리 작업: 역할 변경, 잔액 지급/차감, 보존된 거래의 안전한 되돌림

관리 작업은 기존 서버 도메인 서비스를 호출합니다. 모든 요청에는 구체적인 사유와 UUID 거래 ID가 필요하고, 성공·거부 결과가 권위 있는 감사 로그에 기록됩니다. 경제 거래 되돌림은 인벤토리와 재고를 검증해야 하므로 대상 사용자가 온라인일 때만 실행됩니다.

## 설정

`config/rovenfall-admin-server.toml`에서 다음 값을 조정할 수 있습니다.

```toml
[admin_bridge]
enabled = true
port = 8765
```

설정 변경 후 서버를 재시작해야 합니다. 포트를 바꿨다면 SSH 터널과 접속 URL도 같은 포트를 사용합니다.

## 웹 UI 개발

소스는 같은 저장소의 `admin-web/`에 있습니다. Node.js 22.13 이상과 pnpm을 사용합니다.

```bash
cd admin-web
pnpm install
pnpm dev
```

개발 서버는 `http://127.0.0.1:3000/`에서 열리고 `/api` 요청을 실행 중인 Minecraft 서버의 8765 포트로 프록시합니다. 배포 파일을 JAR 리소스에 갱신할 때는 다음을 실행합니다.

```bash
pnpm typecheck
pnpm build
```

`pnpm build` 결과는 `src/main/resources/assets/rovenfall/admin/`에 생성됩니다. 이후 루트에서 `./gradlew build` 또는 Windows의 `.\gradlew.bat build`를 실행합니다.
