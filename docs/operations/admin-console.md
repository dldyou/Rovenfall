# Rovenfall 로컬 운영 콘솔

Rovenfall 서버가 실행되면 관리 콘솔이 기본적으로 `http://127.0.0.1:8765/`에 열립니다. 콘솔의 정적 파일과 HTTP 브리지는 모드 JAR 안에 함께 들어가므로 별도 웹 서버나 데이터베이스가 필요하지 않습니다.

## 접속

1. Minecraft 서버를 시작합니다.
2. 서버의 `config/rovenfall-admin.token` 파일을 엽니다.
3. 브라우저에서 `http://127.0.0.1:8765/`에 접속한 뒤 토큰을 붙여넣습니다.

토큰은 브라우저 탭의 `sessionStorage`에만 보관되며 탭을 닫으면 사라집니다. 서버 로그에는 토큰 값이 출력되지 않습니다. 토큰 파일 대신 `ROVENFALL_ADMIN_TOKEN` 환경 변수에 32자 이상의 비밀값을 설정할 수도 있습니다.

브리지는 보안을 위해 항상 IPv4 루프백(`127.0.0.1`)에만 바인딩됩니다. 원격 서버를 관리하려면 로컬 PC에서 다음과 같이 SSH 터널을 연 뒤 동일한 로컬 주소로 접속합니다.

```bash
ssh -L 8765:127.0.0.1:8765 user@example-server
```

인터넷에 포트를 직접 공개하거나 토큰 파일을 공유 저장소에 올리지 마세요.

## 기능

- 서버 현황: 온라인/기록 사용자, 최근 24시간 거래와 거래량, 클레임, 상점, 경고 및 거부 건수
- 사용자: 닉네임 또는 UUID 검색, 잔액·역할·커리어·활동 경험치·소유 클레임 조회
- 감사 로그: 전체 텍스트, 사용자, 작업, 결과, 시간 범위 필터, 최근 24시간 거부 프리셋 및 페이지 조회
- 경제·클레임·상점: 거래 영수증, 되돌림 상태, 소유권, 위치, 오퍼 현황 검색
- 관리 작업: 역할 변경, 잔액 지급/차감, 보존된 거래의 안전한 되돌림

관리 작업은 기존 서버 도메인 서비스를 호출합니다. 모든 요청에는 구체적인 사유와 UUID 거래 ID가 필요하고, 성공·거부 결과가 권위 있는 감사 로그에 기록됩니다. 경제 거래 되돌림은 인벤토리와 재고를 검증해야 하므로 대상 사용자가 온라인일 때만 실행됩니다.

## 화면과 단축키

왼쪽 메뉴는 `현황 → 사용자 → 감사 로그 → 경제 → 클레임 → 상점` 순서입니다. 화면 상단에는 항상 현재 위치, 이 화면에서 확인할 정보, 현재 검색 범위가 표시됩니다. 현황의 네 요약 카드는 해당 상세 화면으로 바로 이동합니다.

| 키 | 동작 |
| --- | --- |
| `Ctrl+K` 또는 `/` | 현재 화면의 검색창으로 이동하고 기존 검색어 선택 |
| `Alt+1` … `Alt+6` | 왼쪽 메뉴 순서대로 화면 전환 |
| `Esc` | 상세/도움말 창 닫기, 모바일 메뉴 닫기, 상세 화면에서 현황으로 복귀 |
| `R` | 입력 중이 아닐 때 현재 화면 새로고침 |
| `?` | 단축키와 권장 운영 흐름 열기 |
| `Tab` / `Shift+Tab` | 버튼·입력·필터 사이 이동; 열린 창 안에서 포커스 유지 |

검색은 현재 메뉴 범위에 적용됩니다. 현황에서 검색어를 입력하고 `Enter`를 누르면 사용자 검색으로 이동합니다. 감사 로그는 상단 검색과 함께 사용자, 작업, 결과, 시작·종료 시각 필터를 조합한 뒤 `Enter` 또는 **필터 적용**을 누릅니다. 입력 중에는 서버를 다시 조회하지 않으며, **최근 24시간 거부**와 **필터 초기화**를 자주 쓰는 프리셋으로 제공합니다. 결과가 없으면 먼저 현재 메뉴와 시간 범위를 확인하세요.

## 권장 운영 흐름

1. **현황에서 이상 징후 확인** — 경고와 최근 거부 건수를 보고 요약 카드를 눌러 관련 목록으로 이동합니다.
2. **검색으로 범위 축소** — 닉네임·UUID·거래 ID를 검색하고, 감사 로그에서는 시간과 결과 필터를 함께 사용합니다.
3. **상세에서 현재 상태 확인** — 사용자 상세의 권한·잔액·최근 거래, 경제 목록의 원본 거래와 되돌림 상태를 확인합니다.
4. **영향 미리보기 생성** — 관리 작업에 대상과 구체적인 사유를 입력합니다. 이 단계는 서버 상태를 바꾸지 않습니다.
5. **별도 확정** — 서버가 고정한 변경 전/후 값, 대상 접속 상태, 감사 거래 ID와 만료 시각을 검토합니다. 권한 변경·차감·되돌리기는 `EXECUTE`를 다시 입력해야 합니다.
6. **감사 로그에서 결과 검증** — 완료 메시지의 거래 ID로 감사 로그를 검색해 결과와 사유를 확인합니다.

미리보기는 2분 동안 유효한 일회성 요청이며 최대 128개만 유지됩니다. 미리보기 이후 역할·잔액·원본 거래·접속 상태가 바뀌면 확정은 `STALE_PREVIEW`로 거부되고 감사 기록이 남습니다. 확정 화면은 실수로 사라지지 않도록 `Esc`와 배경 클릭으로 닫히지 않으며, **취소** 또는 **입력 수정**을 명시적으로 선택해야 합니다.

## 자주 쓰는 사용자별 확인

- 사용자 화면에서 닉네임 또는 UUID를 검색한 뒤 이름을 선택하면 권한, 잔액, 커리어, 누적 활동 경험치, 클레임 수, 최근 거래를 한 번에 볼 수 있습니다.
- 사용자 상세의 **이 사용자의 감사 로그**를 누르면 다른 검색 조건을 비우고 해당 사용자 필터가 적용된 감사 화면으로 바로 이동합니다.
- 감사 로그의 **사용자 필터**는 행위자뿐 아니라 대상과 연결된 경제 영수증까지 찾습니다. 특정 사용자의 변경 이력을 확인할 때 전체 검색어보다 우선 사용하세요.
- 경제 화면에서 되돌림 버튼이 비활성화되어 있으면 이미 되돌렸거나 복원으로 무효화된 거래인지 상태 열을 먼저 확인하세요. 인벤토리·재고 검증이 필요한 영수증은 대상 사용자가 온라인이어야 합니다.
- ID는 상세 창에서 복사하고, 사유에는 “수정” 대신 티켓 번호·발생 원인·기대한 결과처럼 나중에 재검토할 수 있는 내용을 적습니다.

## 문제 해결

- **401 / 접속 화면으로 돌아감:** 토큰이 바뀌었거나 서버를 재시작했습니다. 현재 `config/rovenfall-admin.token` 값을 다시 입력합니다.
- **연결 실패:** Minecraft 서버 실행 여부와 `admin_bridge.enabled`, 포트, SSH 터널을 확인합니다. 개발 UI라면 8765 서버가 함께 실행 중이어야 합니다.
- **`PREVIEW_EXPIRED` 또는 `PREVIEW_NOT_FOUND`:** 입력 화면으로 돌아가 새 미리보기를 생성합니다.
- **`STALE_PREVIEW`:** 다른 작업으로 서버 상태가 바뀌었습니다. 목록과 상세를 새로고침한 뒤 변경 전/후 값을 다시 확인합니다.
- **`TARGET_OFFLINE`:** 대상 사용자가 접속한 뒤 원본 거래를 다시 검색하고 새 미리보기를 만듭니다.
- **읽기 전용:** 현황의 쓰기 상태와 서버 로그를 확인합니다. 저장 스키마가 안전하게 열리지 않은 상태에서는 변경을 우회하지 마세요.

## 설정

`config/rovenfall-admin-server.toml`에서 다음 값을 조정할 수 있습니다.

```toml
[admin_bridge]
enabled = true
port = 8765
```

설정 변경 후 서버를 재시작해야 합니다. 포트를 바꿨다면 SSH 터널과 접속 URL도 같은 포트를 사용합니다.

## 웹 UI 개발

소스는 같은 저장소의 `admin-web/`에 있습니다. Node.js 22.13 이상과 pnpm을 사용합니다.

```bash
cd admin-web
pnpm install
pnpm dev
```

개발 서버는 `http://127.0.0.1:3000/`에서 열리고 `/api` 요청을 실행 중인 Minecraft 서버의 8765 포트로 프록시합니다. 배포 파일을 JAR 리소스에 갱신할 때는 다음을 실행합니다.

```bash
pnpm typecheck
pnpm build
```

`pnpm build` 결과는 `src/main/resources/assets/rovenfall/admin/`에 생성됩니다. 이후 루트에서 `./gradlew build` 또는 Windows의 `.\gradlew.bat build`를 실행합니다.
